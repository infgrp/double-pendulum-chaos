# 이중 진자 카오스

처음 각도를 이웃끼리 **0.0001°씩만** 다르게 한 500개의 이중 진자를 한 줄로 세워 동시에 떨어뜨리는 three.js 실험입니다.
이웃한 진자의 팔을 반투명 막으로 이어 두어, 처음에는 한 장의 면처럼 움직이다가 파도처럼 휘고, 마침내 찢어져 흩어지는 모습을 볼 수 있습니다.

`index.html` 한 파일로 동작합니다. 백엔드는 없고, three.js 0.170 을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 기본 실험 (90°, 90°에서 놓음)
| 시간 | 모습 |
|---|---|
| 0 ~ 약 9초 | 한 면처럼 움직임 — 전체 폭 0.05° 는 눈에 안 보임 |
| 약 9 ~ 16초 | 전체 폭이 1°를 넘어 막이 파도처럼 휘고 말림 — 이웃끼리는 아직 이어짐 |
| 약 16초 이후 | 이웃 진자끼리도 10° 넘게 갈라져 막이 찢어짐 (카오스) |

오른쪽 위 그래프는 세로축이 로그 눈금입니다. 차이가 지수적으로 커지므로 거의 직선으로 올라가며, 그 기울기로 리아푸노프 지수(약 0.4/초, 차이가 약 1.6초마다 두 배)를 추정해 보여 줍니다.

## 물리
- 질량 1kg, 길이 1m 인 두 팔, 마찰 없음, g = 9.81 m/s².
- 라그랑주 역학으로 얻은 운동 방정식을 4차 룽게–쿠타(Δt = 1/2000초)로 배정밀도(Float64) 계산합니다. 에너지 오차는 10⁻⁹ 아래로 유지됩니다.
- 진자들은 가운데 진자를 기준으로 양쪽으로 ±0.0001°씩 차이를 줍니다(첫째 팔, 둘째 팔, 또는 둘 다).

## 조작
| 조작 | 동작 |
|---|---|
| ▶ 떨어뜨리기 / Space | 시작·멈춤 |
| ↺ 처음으로 / R | 다시 시작 |
| ← → | 빠르기 |
| 드래그 / 휠 | 회전 / 확대 |
| Tab, ☰ 설정 | 패널 숨기기 |

설정: 진자 수(50~1000), 두 팔의 처음 각도, 각도 차이(0.01° ~ 0.000000001°), 차이를 줄 팔, 빠르기, 막·팔·추·끝 추 궤적 보이기, 색(무지개·불꽃·바다·사탕), 카메라(비스듬히·정면·줄 끝에서·위에서).

## 주소 매개변수
`?t=16&freeze` 는 16초까지 미리 계산해 멈춘 모습, `?run` 은 바로 시작, `?th1=120&th2=120&count=800&delta=0.001` 처럼 설정을 줄 수 있습니다.
